# React Forms & Data Handling

A collection of React practice projects focused on handling user input, form validation, and structured data entry — moving beyond basic controlled inputs into real-world form patterns.

## Projects

### 🔹 Job Application Wizard
A multi-step form that breaks a long job application into manageable steps, with validation at each stage before allowing progression.

**Concepts practiced:** React Hook Form, Yup schema validation, multi-step form state, conditional step rendering, error handling

### 🔹 Expense Tracker
An expense-tracking app for entering, viewing, and managing structured financial entries with real-time UI updates.

**Concepts practiced:** controlled forms, state-driven UI updates, data structuring, list rendering and management

## Tech Stack
React, JavaScript (ES6+), React Hook Form, Yup, Vite
